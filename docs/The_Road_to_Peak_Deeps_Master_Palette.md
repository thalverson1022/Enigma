# The Road to Peak Deeps --- Master Color Palette

This document defines the core art palette for **The Road to Peak
Deeps**.

> Copied into the repo 2026-07-17 as part of `P2:R7:T2 - Apply Visual Style
> Foundations` so the project owns its own source of truth instead of
> depending on a file outside the repo. The palette fork discussed in
> `docs/Phase_2_R7_Style_Implementation_Notes.md` is resolved: this master
> palette (warm browns) is the adopted UI palette, implemented in
> `project/scripts/ui/ui_colors.gd`. The darker/cooler style-guide-mockup
> alternative was rejected after a side-by-side comparison.

## Art Direction

-   1-pixel outlines using `#070403`
-   Lighting from upper-left
-   Hue-shift shadows
-   Reserve white for magical effects and metallic highlights
-   Keep sprites to roughly 10--15 colors from this master palette
