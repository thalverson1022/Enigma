# DawnBringer Attack FX Preview

Open `index.html` in a browser and use the three example buttons to audition
randomized attack-SFX sequences using the current six-file sword FX pool.

The preview varies:

- selected source clip
- timing between hits
- per-hit volume
- playback rate, which also changes pitch in the browser

This is an audition tool only; it does not change the Godot game.
